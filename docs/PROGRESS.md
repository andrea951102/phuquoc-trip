**무엇을**: 바레카 호텔(10장, 모던 트리플룸 객실 사진 2장을 맨 앞에) · 세일링 클럽(9장) 카드에 3썸네일 갤러리 + 라이트박스 연결. 사진은 Agoda API(`/api/cronos/property/BelowFoldParams/GetSecondaryData?hotel_id=`)의 `mosaicInitData.images`에서 Agoda 정렬 순서대로 뽑아 `pix8.agoda.net` 핫링크. 방역 안내 사진 1장은 제외.

**왜**: 사용자가 클라우드 환경에 `www.agoda.com`을 허용해줘서 API 호출 가능해짐.

**검증**: Playwright — 콘솔 에러 없음, 썸네일 src 연결 확인, 라이트박스 열림(1 / 9). 단 컨테이너에서 `pix8.agoda.net`은 여전히 403이라 **실제 사진 표시는 육안 확인 못 함** — 라이브 페이지에서 확인 필요.
