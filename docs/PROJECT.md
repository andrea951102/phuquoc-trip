# PROJECT

## 목적
2027년 환갑 기념 베트남 푸꾸옥 여행 계획을 함께 가는 사람들에게 공유하는 브리핑 웹페이지. 항공권, 일정, 숙소, 맛집, 액티비티를 한 페이지에서 보여준다.

## 배경
나트랑 여행 때 만든 브리핑 페이지(`andrea951102/nhatrang-trip`)가 반응이 좋아서, 같은 구조·디자인을 그대로 가져와 푸꾸옥 환갑 여행용으로 새로 만듦(2026-10-26 복제).

## 이해관계자
- 정상윤(사용자) — 계획 총괄
- 환갑을 맞는 분과 함께 가는 일행 — 페이지를 보고 일정·숙소 결정에 참여

## 범위 밖
- 예약/결제 기능 없음 (외부 예약 사이트 링크로만 연결)
- 백엔드/DB 없음, 정적 페이지 하나로 완결
